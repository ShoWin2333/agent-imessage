# 原生控制台五步改进验收

本轮保留 SwiftUI + TypeScript Gateway 和各后端原生协议，完成 A–E，并按追加要求移除 Web UI。没有操作真实消息渠道或更换用户正在运行的 App。

| 范围 | 实现 | 验收 |
| --- | --- | --- |
| A 任务与结果 | 私有状态中的稳定任务编号、输入、会话、执行配置、完整最终文本；执行与回传状态分离；中断恢复；只重发已有文本 | 回传异常不关闭后端；重发不启动 Agent；重启不重跑；任务不受 200 条诊断事件淘汰影响 |
| B 执行与设置 | Gateway 内按 realpath 协调工作目录；名称/头像/计划即时生效；模型参数下次任务生效；执行边界变更忙碌时拒绝 | 多项目及符号链接目录互斥；不同目录并行；保存元数据不关闭后端；忙碌时拒绝变更且不落盘 |
| C 原生操作 | 任务卡片、侧栏待处理状态、停止、单次审批、问题回答、结果重发 | 稳定任务/请求 ID；过期、重复操作拒绝；跨入口审批隔离；慢速回传不阻塞下一任务或桌面审批 |
| D 定时任务 | 每天/工作日/每周时间选择、高级 Cron、时区、未来五次预览、已保存计划试运行、默认独立会话 | 当前时槽先落盘；忙碌、入口失效、服务/睡眠间隔可解释地跳过；不补跑；时区及 DST 回归 |
| E 能力与维护 | 未知模型能力只显示默认或明确标注的既有设置；完全访问确认；登录项设置入口；启动失败分环节；ETag 轮询；macOS CI | 原生状态/API 契约测试、SwiftUI 编译、服务归属、窗口生命周期及移位安装包验证 |

## 只保留原生界面

删除 `public` 页面、脚本与样式，删除仅用于打开浏览器的编辑器扩展和 App 浏览器菜单。图标迁到 `scripts/macos/Resources/brand.png`。静态页面 URL 返回 404。本机 API 继续限制 loopback Host、Origin 和 CSRF，供原生 App 使用。

## 验证结果

- TypeScript 类型检查、生产编译通过。
- Vitest：24 个文件，130 项测试通过。
- 原生 Store：草稿保护、版本冲突、请求凭据、304 状态复用通过。
- 原生服务：临时 launchd 归属、收养、外部服务保护、退出清理通过。
- 独立测试 App：关窗常驻、重新打开、正常退出、强制结束后收养、启动中退出、外部 Gateway 保留通过。
- 完整 arm64 App 已编译、签名和打包；移位后的最小 PATH、隔离配置、首次启动及重启持久性检查通过。
- 原生虚构数据实点：允许审批后清除请求；重发说明明确“不重新执行”；重发后更新渠道接受状态；工作日预览为下一周五个 09:00；未知模型推理选项只有默认。

产物：`dist/Agent iMessage.app`。代码留在工作区，未发布、未合并。

## 刷新测量

用真实本机 HTTP API、虚构任务，连续执行 30 次条件请求：

| 场景 | 首次响应正文 | 未变响应正文 | 平均请求耗时 |
| --- | ---: | ---: | ---: |
| 空闲示例 | 1,938 B | 0 B | 1.54 ms |
| 200 条约 8 KB 诊断事件 | 1,614,827 B | 0 B | 4.75 ms |

移除了首个入口历史在项目层的重复传输；仍每三秒检查，状态未变返回 304，原生端复用已解析状态。这是本机合成数据的传输测量，不代表真实后端速度或长期内存基准。

## 明确边界

- 目录协调只覆盖本 Gateway，不锁定外部编辑器。
- 回传异常保守标记为未确认，可能已部分送达；重发需明确操作，工具附件不自动重发。
- 定时预览搜索未来一年；服务暂停、睡眠和停机记录为共同的调度间隔，不假定可从时钟间隔判断具体 OS 原因。
- 改变身份、工作目录或后端状态身份时沿用现有会话隔离；不会跨身份自动继承历史。
- 保留现有安全边界；新审批不因入口离线而自动放行。
- 没有对真实 Cursor/Codex/DSH 账户执行付费或有副作用的端到端任务，也没有发送真实微信/iMessage。后端行为通过现有适配器测试及模拟流回归验证。
